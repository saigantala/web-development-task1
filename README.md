# Personal Portfolio Website — Yethendra Sai Gantala

A clean, semantic HTML5 personal portfolio website built for **Week 1: HTML - Your First Website**.

## Project Structure

```text
.
├── index.html          # Main semantic HTML5 portfolio page
├── README.md           # Project overview and setup instructions
├── requirements.txt    # Dependency note (no external packages required)
└── images/
    └── profile.jpg     # Profile portrait photo (ID card removed)
```

## Features Implemented

- **HTML5 Document Structure**: Proper `<!DOCTYPE html>`, `<html lang="en">`, `<head>` metadata, and `<body>`.
- **Semantic HTML**: Uses `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<figure>`, and `<footer>`.
- **Internal Navigation**: Sticky header links (`#about`, `#skills`, `#gallery`, `#contact`) and a back-to-top footer link.
- **About Section**: Profile portrait with descriptive `alt` text, bio, and quick action links.
- **Skills Section**: Categorized skill lists using semantic `<ul>` and `<li>` elements.
- **Milestone Gallery**: Visual cards highlighting core Week 1 HTML5 concepts.
- **Contact Form**: Interactive form with `name`, `email`, and `message` fields, HTML5 validation (`required`, `type="email"`, `minlength`), and an in-page submission confirmation.

## How to Run Locally

1. Open the project folder in **VS Code**.
2. Open `index.html` in any modern web browser (or use the **Live Server** extension in VS Code).
3. Update the GitHub and LinkedIn links in `#contact` with your personal profile URLs before pushing to GitHub.
